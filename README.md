## Project Overview
Letiza Bakery is a real, family-run bakery based in Mzombane, Mokopane, Limpopo. This project involves designing and building a fully functional website for the bakery as part of the WEDE5020 Portfolio of Evidence. The site was chosen because of its real-world relevance and personal connection to the developer's family.

The website introduces Letiza Bakery to the local community online, showcasing its products (bread, cakes, and pastries), sharing the bakery's story and values, and giving customers a simple way to get in touch or enquire about custom orders — particularly celebration cakes.

Part 1 of the POE focuses on planning (proposal and sitemap) and building the core five-page HTML structure with linked CSS and JavaScript. Part 2 and Part 3 will build on this foundation with refined styling, responsive design, and full client-side interactivity (e.g. form validation).

## Website Goals and Objectives
- Give Letiza Bakery a professional online presence reflecting its home-style, community-focused identity.
- Present the bakery's product range (bread, cakes, pastries) clearly, with visual examples of custom cake work.
- Make it easy for customers to enquire about custom cake orders and bulk/event orders.
- Provide clear contact details, location, and opening hours.
- Build a clean, semantic, and accessible HTML5 foundation that can be progressively enhanced with CSS and JavaScript in later parts of the POE.

## Key Features and Functionality
- **Responsive multi-page site** with five core pages: Home, About Us, Products, Enquiry, and Contact.
- **Consistent header/navigation and footer** shared across all pages.
- **Homepage hero section** with an autoplaying bakery video and call-to-action button linking to Products.
- **About page** detailing the bakery's story, mission, vision, and values.
- **Products page** with a categorised product listing (Bread, Cakes, Pastries) and an image gallery of real custom cake orders.
- **Enquiry form** for custom cake and bulk/event order requests, with structured input fields (name, email, phone, order type, message).
- **Contact page** with the bakery's real address, phone number, email, opening hours, an embedded map, and a general contact form.
- **Organised project folder structure** (`css/`, `js/`, `images/`, `docs/`) with linked external stylesheet and script files.

## Part 1 Details
Part 1 of the POE delivers the planning and foundational build of the site:
- A completed website project proposal covering the business, target audience, goals, and site structure.
- A sitemap outlining the five-page structure and navigation flow.
- Semantic HTML5 markup for all five pages (`index.html`, `about.html`, `products.html`, `enquiry.html`, `contact.html`), each sharing a common header, navigation, and footer.
- A linked external stylesheet (`css/style.css`) with base layout, typography, and navigation styling in place.
- A linked external JavaScript file (`js/script.js`) as a placeholder, ready for form validation and interactivity to be added in Part 3.
- A structured `images/` folder containing real bakery product and cake photos.
- Basic (non-validated) `<form>` structures on the Enquiry and Contact pages, marked for client-side validation in Part 3.
